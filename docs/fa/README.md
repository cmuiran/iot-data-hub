## ابزارهای خط فرمان

| ابزار | کار |
|---|---|
| `hub-api` | سرویس اصلی (API و داشبورد وب) |
| `hub-admin` | مدیریت: ساخت مدیر، باز کردن قفل حساب، پشتیبان، بازیابی، بررسی پیش از ارتقا، تست اعلان (`notify-test`) |
| `hub-commission` | راه‌اندازی میدانی، **فقط خواندنی**: خواندن و گزارش، کاوش Modbus/OPC UA/MQTT/SNMP/S7/HTTP |
| `hub` | کنسول جمع‌آوری (بدون API) برای دیدن زندهٔ مقادیر |
| `hub-sim` | شبیه‌ساز همهٔ دستگاه‌ها برای آموزش و تست |
| `python -m hub.validate_config` | بررسی پیکربندی پیش از هر استقرار |

همهٔ فرمان‌ها در پوشهٔ برنامه و با پیشوند `‎.venv\Scripts\` اجرا می‌شوند، مثلاً
`‎.venv\Scripts\hub-commission.exe read`.
